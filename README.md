# Deloitte Data Analytics Virtual Internship (Forage)

This repository contains my solutions for the Deloitte Data Analytics Virtual Experience Program on Forage.

## Task 1: Data Analytics & Dashboarding (Tableau)
- **Objective:** Analyze Daikibo manufacturing telemetry data to identify factory downtime patterns.
- **Key Findings:** Identified **Daikibo Factory Seiko (Osaka, Japan)** as the facility with the highest total downtime, driven primarily by **Laser Welder** failures.
- **Deliverable:** Interactive Tableau dashboard utilizing calculated fields and dynamic filtering.

## Task 2: Forensic Technology - Equal Pay Investigation (Excel)
- **Objective:** Classify equality scores across various factory roles to assess potential pay equity disparities.
- **Methodology:** Implemented nested logical `IF` and `ABS` functions in Excel to dynamically classify scores into **Fair** ($\le \pm10$), **Unfair** ($11–20$), and **Highly Discriminative** ($>20$).
- **Deliverable:** Fully processed `Equality Table.xlsx` dataset.
